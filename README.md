# Bunny Havoc — urso quadrúpede e morte com mais impacto

Baixe e extraia **Bunny_Havoc_Godot_Combate.zip** inteiro em uma pasta nova.
No gerenciador do Godot, escolha Importar e selecione `project.godot`.
Aguarde a importação e aperte F5. No jogo embutido, ative Entrada.

O urso anda nas quatro patas, levanta para preparar a garra e volta ao chão.
A passada usa pares diagonais e mantém o olhar para a frente. As 53 malhas,
a paleta e a escala do modelo original foram preservadas.
A morte parte da pose atual, cai de lado e tem uma pausa curta no impacto,
pequeno ressalto, acomodação, poeira baixa, onda no chão e som grave reforçado.

Esta pasta inclui tudo que já migramos para Godot: Bunnyck, controles,
animações, combo, passos, sons de pulo, corações, vidas e o urso.
WASD/setas movem; K/Ctrl corre; Espaço pula; J/Shift repetidos fazem o combo;
R reinicia. Não é preciso montar nós ou anexar scripts manualmente.

É o projeto Godot completo da etapa atual, com uma arena de teste.
A vila, fases completas, campanha e cutscenes continuam na versão web.
Validado no Godot 4.6.3 Linux; conferência do usuário no 4.7.2 Windows pendente.
32 verificações passaram também após extrair o ZIP, importar e executar.
A prévia MP4 é silenciosa e foi renderizada no Godot real; o som está no jogo.

Esta branch contém somente artefatos. A entrega anterior foi preservada.
