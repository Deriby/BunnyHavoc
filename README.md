# Bunny Havoc — Passinhos

[Baixar componente de passos](Bunnyck_Godot_Passinhos.zip)

Quatro batidas curtas extraídas do Passinhos.wav enviado pelo usuário,
com PCM/ganho originais preservados. Som sincronizado à fase das pernas;
corrida toca mais rápido. Sem loop, sem som parado, no ar ou em ataques.

1. Pare com F8, extraia o ZIP e copie PassosBunnyck para a pasta do projeto,
   junto de project.godot.
2. No Godot, espere importar e arraste res://PassosBunnyck/Passos.tscn sobre
   o nó Jogador. Passos deve aparecer como filho dele.
3. Salve e execute com F6. Ative Entrada e clique na janela do jogo.
4. Para ajustar o volume, selecione Passos e altere Volume dB no Inspetor.
   Inicial -6 dB; 0 dB aumenta, -12 dB diminui.

Não substitui scripts de movimento, animação ou combo; não modifica GLB.
11 verificações passaram no Godot 4.6.3 headless. O usuário usa 4.7.2 e
conferirá aspecto e áudio. Instruções completas em LEIA-ME.txt.
Branch somente de artefatos; não altera main.
