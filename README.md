# Bunny Havoc — Atualização 001

Atualização pequena para **Bunny_Havoc_Godot_Lagarto**. Não é um projeto independente.

Acrescenta a próxima travessia original do Bosque Verde e três cenouras.
A cenoura que estava dentro do buraco foi elevada com autorização do usuário.
Modelos, controles e o céu aprovado permanecem iguais.

1. Feche o Godot.
2. Extraia o ZIP na pasta do jogo que contém `project.godot`.
3. Aceite substituir os arquivos, reabra o projeto e aperte **F5**.

Corra com K/Ctrl e salte com Espaço. R reinicia o percurso.

Validado no Godot 4.4 Compatibility: salto por teclado, coleta, queda,
checkpoint e reinício. O teste aplicou este patch sobre o ZIP anterior real.
