# Bunny Havoc — projeto completo Godot 4.7, atualizado até 012

Projeto independente, com todos os 250 arquivos, modelos, texturas e áudios.
Inclui Fase 1 completa, cutscene, inimigos, cenário vivo, shader PSX enviado
pelo usuário e as sete caixas renovadas. Não precisa de nenhum patch anterior.
Vila e Fase 2 ainda não migradas ao Godot.

1. Feche o Godot e extraia o ZIP em uma pasta NOVA.
2. No gerenciador do Godot 4.7.2, use Importar e selecione project.godot na pasta extraída.
3. Aguarde a importação e aperte F5. Na janela integrada, selecione Entrada.

WASD/setas: mover; K/Ctrl: correr; Espaço: pular; J/Shift: combo.
Enter: diálogos; R: reiniciar; M: som; F2: shader PSX.

Todos os hashes conferidos. Testado diretamente do ZIP extraído, sem patches:
22 verificações da fase, 23 das regras das caixas e 17 de modelos/animações
com renderização nativa, no Godot 4.7.2 Compatibility.
