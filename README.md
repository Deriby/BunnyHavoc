# Bunny Havoc V35 — jogar

[Baixar o jogo completo em ZIP](https://github.com/Deriby/BunnyHavoc/raw/refs/heads/entrega-v35/Bunny_Havoc_V35_JOGAR.zip)

Extraia o ZIP e abra `Bunny_Havoc_V35_Vila_JOGAR.html` no navegador. O jogo usa Three.js pelo CDN e precisa de acesso à internet.

Esta entrega inclui vila com pássaros e rotinas, combo giro → soco → soco e três corações separados das vidas. Há duas fases jogáveis. Upgrades com cenouras continuam como proposta, sem compras ativas.
