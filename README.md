# Bunny Havoc — projeto Godot completo da etapa atual

Baixe e extraia **Bunny_Havoc_Godot_Combate.zip** inteiro em uma pasta nova.
No gerenciador do Godot, escolha Importar e selecione `project.godot`.
Aguarde a importação e aperte F5. No jogo embutido, ative Entrada e clique no jogo.

Inclui Bunnyck original, movimento, animações, combo, passos, três sons de pulo,
urso original com recuo/arremesso e nova queda de costas, três corações e vidas.
WASD/setas movem; K/Ctrl corre; Espaço pula; J/Shift repetidos encadeiam o combo;
R reinicia o treino. Não é necessário montar nós ou anexar scripts.

Esta é a pasta completa do **projeto Godot atual, uma arena de teste**.
A vila, fases completas, campanha e cutscenes ainda estão na versão web preservada.
Não é uma exportação Windows/HTML5. Validado no Godot 4.6.3 Linux;
o usuário conferirá no Godot 4.7.2 Windows. Renderer Compatibility.

O ZIP tem manifesto por arquivo. Importação, boot da cena principal e
25 verificações de combate passaram após extrair em diretório novo.
A prévia MP4 foi renderizada no Godot real com uma câmera de demonstração.
Esta branch contém somente os artefatos de entrega; não altera o main.
