# Bunny Havoc — V40

O combo agora causa dano 1 → 1 → 2 contra inimigos. O último soco arremessa o alvo com um arco cartunesco; o urso vai menos longe. Se sobreviver, cai e recupera-se antes de voltar à luta. Paredes, caixas e bordas limitam o deslocamento. Recompensas continuam sendo concedidas uma vez por derrota.

[Baixar o ZIP](https://github.com/Deriby/BunnyHavoc/raw/refs/heads/entrega-v40/Bunny_Havoc_V40_JOGAR.zip)

Extraia e abra `Bunny_Havoc_V40_Vila_JOGAR.html` no navegador. O HTML contém o jogo completo e a música da vila; precisa de internet para carregar o Three.js do CDN original. Basta baixar o ZIP ou o HTML separado.

J/Shift: toques sucessivos para encadear giro → soco → soco final. Segurar executa somente o giro. Mantidos os passos curtos, animações e alcance da V39. Pisões e resistência das caixas seguem as regras anteriores.

Mantidos três corações, modelos, fases, vila viva, música tema e ciclo de dia/noite. O horário da vila é mantido durante a sessão; recarregar reinicia de manhã.
